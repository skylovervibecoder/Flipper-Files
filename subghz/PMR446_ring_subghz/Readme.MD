# PMR446 Channel Ringer

This project contains files designed to trigger a ringing signal on selected PMR446 channel frequencies using compatible hardware and software.

## Overview

The PMR446 Channel Ringer provides access to the 16 standard PMR446 analogue channel frequencies, ranging from 446.00625 MHz to 446.19375 MHz, with 12.5 kHz channel spacing.

Each file is intended to trigger the ringing signal associated with its corresponding PMR446 frequency on a compatible device.

## How to Use

1. Identify the desired PMR446 channel in the list above.
2. Select the file associated with that channel frequency.
3. Open the file using the compatible application or device.
4. Activate the supported function to trigger the corresponding channel's ringing signal.

Actual behavior depends on the file format, device hardware, firmware, and application implementation.

## Technical Specifications

- **Frequency band:** 446.0–446.2 MHz
- **Number of analogue channels:** 16
- **Channel spacing:** 12.5 kHz
- **Modulation:** Typically narrowband FM (analogue PMR446)
- **Use case:** Channel selection and RF testing with compatible equipment
